# dotnetdll 0.5.0

Resolved IL can now represent and round-trip `constrained.` and `tail.` together
on a `callvirt`:

```rust,ignore
Instruction::CallVirtualConstrainedTail(constraint_type, method)
```

The reader accepts either prefix order and the writer emits `constrained.` then
`tail.`. Calls with either prefix alone retain their existing variants. Tests
cover both orders, branch offsets, and a .NET 10 probe that returns `42`.

## Migration

Set `dotnetdll = "0.5"` in `Cargo.toml`. Exhaustive matches on the public resolved
and binary IL instruction enums must handle their new variants. See the
[migration guide](https://github.com/nickbclifford/dotnetdll/blob/v0.5.0/docs/migration-0.5.md)
and [full changelog](https://github.com/nickbclifford/dotnetdll/blob/v0.5.0/CHANGELOG.md).
Rust 1.85.1 remains the minimum supported compiler; `dotnetdll-macros` remains
at 0.2.1.
