# dotnetdll 0.4.0

This release makes metadata parsing substantially faster under Miri Tree Borrows
by allowing retained heap values to use the `Cow::Owned` variants already present
in the public API. Native zero-copy heap behavior remains the default.

```rust
use dotnetdll::prelude::ReadOptions;

const OPTIONS: ReadOptions = ReadOptions::new()
    .with_lazy_method_bodies(true)
    .with_lazy_attributes(true)
    .with_own_heap_values(cfg!(miri));
```

## What changed

- Added opt-in ownership of retained metadata strings and blobs, including values
  returned by lazy attribute accessors.
- Replaced persistent per-method body slices with ranges into one shared input
  slice. This reduces live borrows without copying IL or changing public lifetimes.
- Added const builders for every read option and a const `ReadOptions::new()`.
- Fixed `skip_method_bodies` taking precedence over lazy bodies, while preserving
  independent lazy signatures, properties and attributes.
- Added MSRV and Tree Borrows CI jobs, plus ownership and deferred-body regressions.

In a controlled comparison using the 46,592-byte dotnet-rs support DLL and
nightly-2026-05-27 Tree Borrows, `p00_smoke` fell from **271.04 s to 35.11 s** and
`batch_2` from **234.29 s to 40.10 s**. Native default benchmarks showed no
material regression. These observations are specific to that fixture and
toolchain. Full CoreLib Miri parsing was not timed; native CoreLib benchmarks and
memory measurements are documented in the
[research report](https://github.com/nickbclifford/dotnetdll/blob/v0.4.0/research/owned-heaps/REPORT.md).

## Migration

Set `dotnetdll = "0.4"` in `Cargo.toml`. `ReadOptions` is now non-exhaustive:
replace downstream struct literals, including those with `..Default::default()`,
with `new()`/`default()` and builders or field assignments. Const configurations
can use the same builders after `new()`. Destructuring patterns must include `..`.

Public resolved field types and lifetimes are unchanged. Owned heaps still
require the original input to outlive the resolution. Rust **1.85.1** remains the
minimum supported compiler. The macros crate remains at **0.2.1**.

See the [migration guide](https://github.com/nickbclifford/dotnetdll/blob/v0.4.0/docs/migration-0.4.md)
and [full changelog](https://github.com/nickbclifford/dotnetdll/blob/v0.4.0/CHANGELOG.md).
